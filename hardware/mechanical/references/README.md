# references/

Datasheets, measurements, photos, and other design inputs used to model parts —
e.g. motor/servo/shield dimensions. For Freenove-kit datasheets, check
`../../../freenove-car-reference/Datasheet/` first (a local, gitignored reference
clone — not tracked in this repo, see `CLAUDE.md`) instead of duplicating them here;
put things here that are Mini-Ultron-specific (own measurements, photos, sketches)
or that need to travel with this repo.
